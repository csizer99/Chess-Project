# Usage
Functioning chess game, where you can play against a trained AI at around a 500-600 chess.com elo level, or
play against a friend. 

# Instructions to load model

Use model weights found in "chess_model_final.pth". "chess_model.pth" should have correct weights, however
may not have had most finalized updates
